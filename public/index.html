        Apparence
        Missions Un profil par client : thème, rubriques affichées et leur ordre, motif de production du voyant kubectl, dossier des nouveaux terminaux, groupe de favoris ouvert par la touche Favoris. Activation par le sélecteur « Mission » de l'en-tête.
          Mes actions Tes propres rubriques et touches, sans éditer de fichier : une commande (exécutée tout de suite, ou à compléter ; {} = texte sélectionné dans le terminal) ou un lien. Enregistrées dans actions.json, hors Git. Une rubrique créée apparaît aussi dans « Rubriques » ci-dessous.
          Nouvelle rubrique
          Nouvelle action
          Rubriques Mondes affichés sur l'accueil ; décochés, ils sont masqués partout (palette ⌘K comprise). Les rubriques du catalogue absentes de config.jsonc (ex. Sécurité, Vault) peuvent être activées ici. Glisse une case pour changer l'ordre de l'accueil.
          Navigation Après une action dans une rubrique (Docker, K8s, Git…), le deck revient à l'accueil si aucune autre action n'y est lancée pendant ce délai ; chaque action relance le compte à rebours.
          Serveur
            Sauvegardes Copies automatiques avant chaque modification (au plus une toutes les 10 min, toujours avant un remplacement), 10 gardées par fichier dans .deck-backups/, hors Git. Restaurer sauvegarde d'abord la version actuelle.
            Favoris Pour retrouver tes favoris sur une autre machine : exporte-les ici, puis importe le fichier là-bas. Le fichier contient les adresses de mission : garde-le hors des dépôts et des partages publics.
            Coffre Pour retrouver notes et secrets sur une autre machine. Le fichier exporté reste chiffré par ton mot de passe maître ; à l'import, il faut le mot de passe maître du fichier.

            Réglages enregistrés côté serveur (settings.json, hors Git) : les mêmes pour tous les onglets et navigateurs.
